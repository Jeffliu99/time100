# Time100 V1 Product Requirements

## Product position

Time100 helps users turn goals into projects, projects into tasks, and completed actions into a visible growth journey.

## V1 principles

1. Keep the feature set focused.
2. Make the core workflow stable and pleasant.
3. Design mobile first.
4. Protect every private page and API.
5. Create a clear path toward a native-style app.
6. Treat Nova as a future product differentiator without delaying the stable V1 release.

## Core V1 workflow

1. User visits the public homepage.
2. User signs in.
3. First-time user completes a short profile onboarding.
4. User creates a project.
5. Add Task remains disabled until a project exists.
6. User creates and manages tasks.
7. Completion creates a Growth Event and an optional celebration.
8. Timeline displays completed growth events.

## V1 scope

- Authentication
- User-owned projects and tasks
- Project and task CRUD
- Dashboard statistics
- Task board
- Project progress
- Growth Timeline
- Basic Nova companion presence
- User Profile
- Mobile-first navigation
- Public homepage
- About, FAQ, Contact, Privacy, and Terms pages

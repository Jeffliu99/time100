# Time100 Documentation

This directory is the center for Time100 product and development specifications.

## Core Principle

Major designs must be documented in the specifications before code is generated or modified.

## File Structure

- `time100-design-spec.md`: Master product specification and single source of truth
- `roadmap.md`: Version roadmap
- `changelog.md`: Specification change log
- `database-design.md`: Core data model documentation
- `api-spec.md`: Core API conventions
- `features/`: Feature specifications

## Development Workflow

```text
Idea
-> Design Spec
-> Feature Spec
-> Implementation
-> Build
-> Review
-> Commit
-> Push
```

# Time100 Documentation

本目录是 Time100 的产品与开发规范中心。

## 核心原则

重大设计必须先更新规范，再生成或修改代码。

## 文件结构

- `time100-design-spec.md`：产品总规范与唯一事实来源
- `roadmap.md`：版本路线图
- `changelog.md`：规范变更记录
- `database-design.md`：核心数据模型说明
- `api-spec.md`：核心 API 约定
- `features/`：各功能的 Feature Spec

## 开发流程

```text
Idea
→ Design Spec
→ Feature Spec
→ Implementation
→ Build
→ Review
→ Commit
→ Push
```

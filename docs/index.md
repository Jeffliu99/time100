## Development Principle

Time100 follows Specification First Development (SFD).

```text
Idea
-> Design Spec
-> Feature Spec
-> Implementation
-> Build
-> Review
-> Commit
-> Push
```

Specifications are the Single Source of Truth.

Major features must be specified before implementation begins.

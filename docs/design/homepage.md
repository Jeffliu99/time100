# Public Homepage

## Purpose

The homepage introduces Time100 before login and helps visitors decide whether to start using the product.

## Hero

- Time100 Logo
- Turn Ideas Into Reality
- A short explanation of the Growth Operating System
- Primary CTA: Get Started
- Secondary CTA: Log In
- Product or Nova visual

## Product story

Explain the journey:

```text
Idea → Goal → Project → Task → Growth
```

## Feature sections

- Goals and Profile
- Projects
- Tasks
- Growth Timeline
- Nova AI Companion
- Completion celebrations
- Personal memory and progress

## Nova section

Position Nova as an intelligent growth companion that can help users:

- Clarify goals
- Create projects and tasks after confirmation
- Review progress
- Remember important information
- Explain upcoming Time100 features
- Collect product feedback

## Future section

Clearly label unreleased items as coming soon.

## Trust section

- A product of eSeeSKy Inc.
- Privacy-first messaging
- Product version
- Contact information

## Mobile behavior

- Compact sticky public header
- Strong first-screen CTA
- Short sections
- Large buttons
- Optimized images
- No horizontal overflow

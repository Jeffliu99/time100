# Privacy and Data Principles

## Data minimization

Collect only information needed to provide the product experience.

## Initial profile

Do not require:

- Exact birth date
- Street address
- Government identifiers
- Unnecessary sensitive information

Country and optional city are sufficient for the initial experience.

## User rights and controls

Users should be able to:

- View profile data
- Edit profile data
- Delete memories
- Delete account data
- Export data in a future version

## Company attribution

Privacy and legal pages should identify the product operator as eSeeSKy Inc. and provide a valid contact method before public launch.

## AI transparency

- Explain when users are interacting with AI
- Explain whether a message may be stored as memory
- Avoid promising perfect confidentiality without a verified policy
- Document external model and speech providers before enabling them

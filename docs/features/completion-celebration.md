# Completion Confirmation and Celebration

## Objective

Give task and project completion a small sense of ceremony without slowing down normal use.

## Flow

1. User taps Complete.
2. Show a confirmation dialog.
3. User confirms completion.
4. Persist the completed state.
5. Create a Growth Event.
6. Show a short Nova celebration.
7. Display a badge, stamp, or achievement visual.
8. Automatically dismiss the celebration after a few seconds.
9. Move the item into the completed group.

## V1 pilot

- One confirmation dialog
- One lightweight celebration animation
- Nova congratulatory message
- One completion stamp or badge style
- Reduced-motion support
- No long blocking animation

## Future

- Generated achievement cards
- Shareable completion images
- Badge collections
- Milestone tiers
- Character-specific celebrations

# Nova AI Companion

## Vision

Nova should become a useful, natural growth companion rather than a fixed message widget.

## V1 preparation

Before connecting a large language model:

- Define Nova's purpose
- Define safety and tone rules
- Define supported actions
- Define memory boundaries
- Define subscription and usage limits
- Design text-first mobile chat

## AI chat capabilities

- Text chat
- Goal clarification
- Project planning
- Task breakdown
- Progress review
- Motivation and accountability
- Time100 feature and roadmap explanations
- Feedback collection

## Action flow

Nova may detect an actionable intention, but must ask for confirmation before creating or changing data.

Example:

```text
User: I need to prepare for an exam next month.
Nova: Would you like me to create an Exam Preparation project and draft the first tasks?
```

## Voice roadmap

Later versions may support:

- Speech-to-text
- Spoken responses
- Hands-free mode
- Driving-friendly interaction

Voice use should have clear usage limits because model and speech services create variable cost.

## Personality system

Initial characters:

- Supportive companion
- Direct accountability coach

Future personalities:

- Gentle mentor
- Strict coach
- Study coach
- Strategic planner
- Friendly companion

Each character requires a defined tone, reasoning style, boundaries, and coaching method.

## Conduct rules

- No abusive or degrading language
- No manipulative pressure
- No pretending to be a licensed professional
- Respect user preferences
- Be clear when an answer is uncertain
- Protect personal information

## Design Principles

Every feature should reinforce at least one of the following values:

- Growth
- Reflection
- Companionship
- Long-term value

Features should not prioritize productivity pressure, streak anxiety, or artificial engagement.

## Specification Rule

Feature specifications must be updated before implementation begins.

Specifications are the Single Source of Truth.

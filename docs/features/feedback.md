# Product Feedback Through Nova

## Purpose

Nova can serve as a conversational feedback channel for Time100.

## Capabilities

- Ask what users want improved
- Collect feature requests
- Capture usability problems
- Ask short follow-up questions
- Save feedback with user consent

## Feedback record

Suggested fields:

- User ID
- Category
- Summary
- Original message or approved excerpt
- Product area
- Priority signal
- Created date
- Status

## Nova behavior

Nova should distinguish between:

- A goal or task request
- A support issue
- General conversation
- Product feedback

Nova should confirm before submitting feedback and tell the user that feedback was recorded.
